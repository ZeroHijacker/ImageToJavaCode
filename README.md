# Portrait Studio

Version 0.2.1 for Windows x64. Convert a reference image into a standalone Java 2D drawing program using local, non-neural image processing.

## Start here

1. Open `PortraitStudio-0.2.1-Windows-x64.msi` and follow the installation wizard.
2. Launch **Portrait Studio** from the Start menu or desktop shortcut.
3. Drop one image onto the portrait preview and choose a Java destination.
4. Review the rendered portrait, Java source, and technique report. Adjust settings and select **Regenerate** when needed.
5. Select **Save Java + assets ZIP** to keep the reviewed result.

The installer includes Java and Python. Installation and image conversion work offline; no separate runtime setup is required. Read `INSTALLATION.md` for installation and removal, and open `USER_GUIDE.html` for the complete workflow. The application's **User guide** button opens the same offline guide.

## What the application provides

- Explicit Java 2D drawing statements, with source-line and shape limits.
- Original, Realism, Mosaic, Abstract, Cubism, Minimalist, and Pixelated styles, plus seven recoloring choices.
- Image and source previews before saving, session image retention, and manual regeneration.
- Shape and visible-technique counts, overlap-depth layers, optional comments, and keyboard layer navigation.
- Dark and light themes with contrasting checkbox marks.
- A standalone Java file and one companion ZIP containing the supporting images and reports.

The application aims to use ten graphics technique families meaningfully. Image content and tight budgets can reduce coverage and likeness. Review the report and rendered result rather than assuming a guaranteed score.
