# Contributing and Reporting Problems

Build the application using `BUILDING.md`. Keep changes focused and preserve standalone Java output, local processing, and the preview-before-save workflow. Test the affected behavior and record the commands and results in your change description.

For a reproducible issue, include the application version, Windows version, chosen budgets and styles, expected behavior, actual behavior, and any error text. Prefer a synthetic image that demonstrates the problem. Do not attach personal photographs or unredacted local paths by default.

No public repository or support address is configured in this local release. The distributor should supply those details on the eventual download page. Report suspected security issues privately to the distributor instead of posting sensitive files in a public issue.

Contributions to original application code should be compatible with the MIT License. Preserve dependency notices and document any newly introduced libraries, runtime downloads, or network behavior.
